# Resume Website

A clean, modern portfolio website showcasing projects and work experience.

## Features

- **About Me** section
- **Projects** section with links to GitHub repos and live demos
- **Resume/Work Experience** section
- Responsive design that works on all devices
- Smooth scrolling navigation
- Modern, clean UI similar to professional portfolio sites

## Setup for GitHub Pages

1. **Create a GitHub repository** named `yourusername.github.io` (replace `yourusername` with your GitHub username)

2. **Upload this file** to your repository:
   - `index.html` (this is the main file)

3. **Enable GitHub Pages**:
   - Go to your repository settings
   - Scroll to "Pages" section
   - Select the branch (usually `main` or `master`)
   - Your site will be live at `https://yourusername.github.io`

## Customization

Edit `index.html` and update:

1. **Personal Information**:
   - Replace "Your Name" with your actual name
   - Update the hero section subtitle
   - Modify the About Me section

2. **Projects**:
   - Copy the project card template
   - Update project names, descriptions, and links
   - Add or remove projects as needed

3. **Resume**:
   - Copy the resume item template
   - Add your work experience
   - Update dates, companies, and responsibilities

4. **Styling** (optional):
   - Modify colors in the `<style>` section
   - Adjust spacing, fonts, or layout as desired
