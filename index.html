Featured Projects

Autonomous Navigation with Reinforcement Learning in NVIDIA Isaac Lab

Built a reinforcement learning simulation environment where a four-wheel vehicle learns to autonomously navigate through a series of waypoints while avoiding obstacles. The system uses LiDAR-based ray casting to detect nearby objects and feed environmental data into the RL policy.

The vehicle is trained using Proximal Policy Optimization (PPO) with the RSL-RL framework, enabling it to learn collision avoidance and path navigation within a physics-based simulation powered by NVIDIA Isaac Lab.

Violence Detection

Built a real-time violence detection system that analyzes video footage using computer vision and deep learning. The pipeline uses YOLO pose estimation to extract human body keypoints and combines pose features with image data in a custom CNN + Transformer model to classify violent versus non-violent actions.

The system includes tools for dataset auditing, preprocessing, video slicing, and model training, along with an inference client that processes video streams and applies configurable detection thresholds.

Automatic License Plate Recognition System

Built an end-to-end computer vision system that detects and reads vehicle license plates from video. The pipeline uses YOLO for license plate detection, crops detected regions, and applies OCR models such as EasyOCR/PaddleOCR to recognize plate characters.

The system supports processing video streams and storing cropped plate images for separate OCR processing, allowing the detection and recognition stages to run independently for better scalability.
